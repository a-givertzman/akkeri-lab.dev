CraneWare.ShipBoard — Крановое судовое программное обеспечение

Программное обеспечение предназначенное для управления судовыми кранами различной конструкции и функционалом. Области применения:
  • Промышленные грузоподъемные механизмы;
  • Грузоподъемные механизмы грузовых судов.

Для получения информации о способах приобретения права использования наших продуктов и стоимости их использования свяжитесь с нами по почте: info@sa-lab.dev

Общая информация

Программа состоит из следующих функциональных блоков, списков переменных и программ.

Списки входов/выходов контроллера: AnalogInputs, AnalogOutputs, DigitalInputs, DigitalOutputs.

Для каждого из типа входов/выходов создан отдельный список глобальных переменных (входы, выходы, аналоговые, дискретные)

Настройка модулей и внешних устройств контроллера осуществляется через шину FBUS.

Модули вводятся согласно схеме подключения, удалённые — настраиваются отдельно для соответствующих портов.

Подключение через Modbus RTU RS-485

У каждого из устройств настраиваются параметры Modbus.

Привязка входов и выходов

Привязываются входные переменные в окне «Inputs» и выходные переменные в окне «Outputs». Если между входами/выходами есть разрыв в адресном пространстве, то необходимо создать дополнительный блок «Inputs» или «Outputs», чтобы опрос проходил без пробелов в адресах, иначе весь опрос работать не будет. Если разрыв в адресах небольшой (1-2 пункта) можно создать пустые переменные.
